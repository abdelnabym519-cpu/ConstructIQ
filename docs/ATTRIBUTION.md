# Open-Source Attribution

ConstructIQ was bootstrapped from the MIT-licensed repository:

**LHB-Group/Civil-Work-Bidding-And-Investment-Helper**

The original project provided a historical construction-cost prediction baseline and legacy Streamlit application. The original MIT license is retained in this repository.

## ConstructIQ Enhancements

ConstructIQ adds or substantially changes:

- Apache Spark / PySpark foundation
- Bronze / Silver / Gold medallion architecture
- official DataSF large-scale ingestion
- schema normalization and data-quality processing
- ML-ready Gold feature pipeline
- temporal machine-learning evaluation
- NLP project-description features
- ML diagnostics and V2 revised-cost-only policy
- Explainable AI ablation analysis
- interpretable CountVectorizer companion model
- Model Card
- ConstructIQ analytics dashboard
- Dockerized Spark ML and dashboard environments
- reproducible EDA and model-result reports

ConstructIQ does not claim authorship of the original baseline code.
